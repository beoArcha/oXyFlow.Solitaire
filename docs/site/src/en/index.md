# oXySol

Fourteen solitaire games for the terminal: **Klondike, Spider, FreeCell, Pyramid, the Yukon family and Golf**, in one
program, `oxysol`. It runs in any modern terminal and is played with the keyboard or the mouse.

![Klondike in oXySol: the board, the guide panel and the possible moves panel](../img/en/klondike.svg)

**Status:** pre-release, in development.
