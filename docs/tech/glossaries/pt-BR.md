# Brazilian Portuguese Glossary (pt-BR)

Brazilian Portuguese texts in oXySol must use this glossary for consistency.

| English | Brazilian Portuguese | Notes |
|---|---|---|
| foundation | fundação | Base de destino do ás ao rei por naipe (Plural: fundações) |
| tableau / column | coluna | Pilha de jogo na mesa (Plural: colunas) |
| stock | monte | Pilha de compras / reserva de cartas |
| waste | descarte | Cartas abertas viradas do monte |
| free cell | célula livre | Espaço temporário em FreeCell (Plural: células livres) |
| run | sequência | Sequência ordenada de cartas |
| run size | sequência | Quantidade de cartas movidas juntas (Barra de ações: `+/-: sequência`) |
| restart (a game) | reiniciar | Reiniciar a partida (Cabeçalho: `Reinícios: {count}`, Botão: `Reiniciar`) |
| win without a restart | sem reinício | Coluna de estatísticas: `Sem reinício` |
| no undo | sem desfazer | Cabeçalho e estatísticas: `Sem desfazer` |
| win rate | Taxa % | Coluna de estatísticas |
| best time | Melh. tempo | Coluna de estatísticas abreviada para caber em 100 colunas |
| fewest moves | Menos jog. | Coluna de estatísticas abreviada para caber em 100 colunas |
| hints and help | dicas e ajuda | Grupo nas configurações |
| target marks | marcas de destino | Indicadores de destinos válidos |
| quick options | opções rápidas | Painel de opções durante o jogo |
| face-up / face-down | aberta / oculta | Estado das cartas; virar para cima / virar para baixo |
| pick up / drop / put back | pegar / soltar / devolver | Ações de movimentação de cartas |
| undo / redo | desfazer / refazer | Desfazer ou refazer jogadas |
| seed | semente | Valor numérico aleatório para a distribuição da partida |
| hint | dica | Sugestão de jogada |
| quick move | jogada rápida | Envio direto para o melhor destino |
| Spider | Spider | Inalterado |
| Pyramid | Pirâmide | Com acento circunflexo em português |
| Klondike | Klondike | Inalterado |
| FreeCell | FreeCell | Inalterado |
| Draw 1 / Draw 3 | 1 carta / 3 cartas | Modo de compra no Klondike |
| Relaxed / Classic | relaxada / clássica | Variantes de Pirâmide |
| tab (UI) | aba | Aba da interface (Tecla do teclado: Tab) |
| dock (help window) | ancorar | Ancorar a janela de ajuda lateralmente |
