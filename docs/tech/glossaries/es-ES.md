# Spanish Glossary (es-ES)

Spanish texts in oXySol must use this glossary for consistency.

| English | Spanish | Notes |
|---|---|---|
| foundation | base | Pila de destino del as al rey por palo (Plural: bases) |
| tableau / column | columna | Pila de juego en el tapete (Plural: columnas) |
| stock | mazo | Pila o montón para robar cartas |
| waste | descarte | Montón de cartas descubiertas robadas del mazo |
| free cell | celda libre | Espacio temporal en FreeCell (Plural: celdas libres) |
| run | secuencia | Secuencia ordenada de cartas |
| run size | secuencia | Número de cartas movidas juntas (Barra de acciones: `+/-: secuencia`) |
| restart (a game) | reiniciar | Reiniciar la partida (Encabezado: `Reinic.: {count}`, Botón: `Reiniciar`) |
| win without a restart | sin reinicio | Columna de estadísticas: `Sin reinicio` |
| no undo | sin deshacer / sin desh. | Encabezado abreviado: `Sin desh.`; estadísticas: `sin deshacer` |
| win rate | % ganadas | Columna de estadísticas |
| best time | Mej. tiempo | Columna de estadísticas abreviada para caber en 100 columnas |
| fewest moves | Menos mov. | Columna de estadísticas abreviada para caber en 100 columnas |
| hints and help | pistas y ayuda | Grupo en ajustes |
| target marks | marcas de destino | Indicadores de destinos válidos |
| quick options | opciones rápidas | Panel de opciones durante el juego |
| face-up / face-down | boca arriba / boca abajo | Estado de las cartas; descubierta / boca abajo |
| pick up / drop / put back | coger / soltar / devolver | Acciones de movimiento de cartas |
| undo / redo | deshacer / rehacer | Deshacer o rehacer jugadas |
| seed | semilla | Valor numérico aleatorio para repartir la partida |
| hint | pista | Recomendación de jugada |
| quick move | jugada rápida | Envío directo al mejor destino |
| Spider | Spider | Sin cambios |
| Pyramid | Pirámide | Con tilde en la a |
| Klondike | Klondike | Sin cambios |
| FreeCell | FreeCell | Sin cambios |
| Draw 1 / Draw 3 | 1 carta / 3 cartas | Modo de robo en Klondike |
| Relaxed / Classic | relajada / clásica | Variantes de Pirámide |
| tab (UI) | pestaña | Pestaña de la interfaz (Tecla: Tab) |
| dock (help window) | anclar | Anclar la ventana de ayuda a un lado |
