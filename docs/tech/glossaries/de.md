# German Glossary (de-DE)

German texts in oXySol must use this glossary for consistency.

| English | German | Notes |
|---|---|---|
| foundation | Fundament | Zielfeld / Ablagestapel von Ass bis König (Plural: Fundamente) |
| tableau / column | Spalte | Spielstapel / Spalte (Plural: Spalten) |
| stock | Talon | Nachziehstapel |
| waste | Ablagestapel | Vom Talon gezogene/aufgedeckte Karten |
| free cell | Freie Zelle | Reservierte Ablagezelle in FreeCell |
| run | Folge | Zusammenhängende Kartenfolge |
| run size | Folgenlänge | Anzahl der zusammen bewegten Karten |
| restart (a game) | neu starten | Neustart (Header: `Neustarts: N`, Button: `Neu starten`) |
| win without a restart | ohne Neustart | Statistik-Spalte: `Ohne Neustart` |
| hints and help | Hinweise und Hilfe | Gruppe in Einstellungen |
| target marks | Zielmarkierungen | Markierungen möglicher Ablageorte |
| quick options | Schnelloptionen | Optionen-Panel im Spiel |
| face-up / face-down | offen / verdeckt | Kartenstatus; aufdecken = umdrehen |
| pick up / drop / put back | aufnehmen / ablegen / zurücklegen | Kartenaktionen |
| undo / redo | rückgängig / wiederholen | Züge zurücknehmen / wiederherstellen |
| seed | Seed | Zufallswert für Spielverteilung |
| hint | Hinweis | Zug-Empfehlung |
| quick move | schneller Zug | Direkt auf bestes Ziel legen |
| Spider | Spider | Unverändert |
| Pyramid | Pyramide | Eingedeutscht mit -e |
| Klondike | Klondike | Unverändert |
| FreeCell | FreeCell | Unverändert |
| Draw 1 / Draw 3 | 1 Karte / 3 Karten | Ziehmodus in Klondike |
| Relaxed / Classic | entspannt / klassisch | Spielarten von Pyramide |
| tab (UI) | Reiter | UI-Reiter (Tastatur-Taste: Tab) |
