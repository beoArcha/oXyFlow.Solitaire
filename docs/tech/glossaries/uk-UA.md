# Ukrainian Glossary (uk-UA)

Ukrainian texts in oXySol must use this glossary for consistency.

| English | Ukrainian | Notes |
|---|---|---|
| foundation | база | Базове поле / стос від туза до короля (Множина: бази) |
| tableau / column | стовпець | Ігровий стос / колонка (Множина: стовпці) |
| stock | колода | Резерв карт для добору |
| waste | скид | Карти, відкриті/добрані з колоди |
| free cell | вільна комірка | Тимчасове поле у FreeCell (Множина: вільні комірки) |
| run | ряд | Послідовний ланцюжок карт |
| run size | довжина ряду | Кількість карт, які переміщуються разом |
| restart (a game) | спочатку | Розпочати гру знову (Заголовок: `Спочатку: {count}`, Кнопка: `Спочатку`, Дія: `Shift+R: спочатку`) |
| win without a restart | чисті | Колонка статистики: `Чисті` |
| best time | кращий час | Колонка статистики: `Кращий час` |
| fewest moves | мін. ходів | Колонка статистики: `Мін. ходів` (скорочено для ширини 100 колонок) |
| without undo | без скасування | Заголовок гри: `Без скасування` (Статистика: `без скасування`) |
| unknown (solvable?) | невідомо | Розв'язність не перевірена або невизначена: `Виграшна: невідомо`, Легенда: `? невідомо` |
| not checked | неперевірено | Розв'язність не перевірялася: `· неперевірено` |
| Page Up / Page Down | PgUp/PgDn | Коротка форма в підказках клавіш |
| rejected move | Неприпустимий хід: … | Префікс усіх `board.error.*`; усе повідомлення щонайбільше 40 символів |
| hints and help | підказки та допомога | Група в налаштуваннях |
| target marks | позначки цілей | Маркери можливих місць переміщення карт |
| quick options | швидкі опції | Панель швидких опцій у грі |
| face-up / face-down | відкрита / закрита | Стан карти; відкрити / перевернути |
| pick up / drop / put back | взяти / покласти / повернути | Дії з картами |
| undo / redo | скасувати / повторити | Скасування або повторення ходів |
| seed | зерно | Випадкове число генерації роздачі (seed) |
| hint | підказка | Рекомендація ходу |
| quick move | швидкий хід | Пряме переміщення на найкраще цільове місце |
| Spider | Павук | Українська назва гри |
| Pyramid | Піраміда | Українська назва гри |
| Klondike | Klondike | Міжнародна назва; «Косинка» лише там, де дозволяє місце |
| FreeCell | FreeCell | Без змін |
| Draw 1 / Draw 3 | 1 карта / 3 карти | Режим роздачі в Klondike |
| Relaxed / Classic | вільна / класична | Варіанти Піраміди |
| tab (UI) | вкладка | Вкладка інтерфейсу (Клавіша: Tab) |
| dock (help window) | прикріпити | Прикріпити вікно довідки збоку |
