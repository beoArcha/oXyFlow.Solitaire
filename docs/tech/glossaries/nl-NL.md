# Dutch Glossary (nl-NL)

Dutch texts in oXySol must use this glossary for consistency.

| English | Dutch | Notes |
|---|---|---|
| foundation | fundament / basis | Doelstapels van aas tot koning per kleur (Kop: `Basis {number}`) |
| tableau / column | kolom | Speelkolommen op het bord (Meervoud: kolommen) |
| stock | stapel | Trekstapel / voorraadkaarten |
| waste | aflegstapel | Open kaarten getrokken van de stapel |
| free cell | vrije cel | Tijdelijk vak in FreeCell (Meervoud: vrije cellen) |
| run | reeks | Geordende kaartenreeks |
| run size | selectiegrootte | Aantal kaarten dat samen bewogen wordt (`+/-: selectiegrootte`) |
| restart (a game) | opnieuw / herstart | Spel opnieuw starten (Header: `Herstart: {count}`, Knop: `Opnieuw starten`, Actie: `Shift+R: opnieuw`) |
| win without a restart | zonder herstart | Statistiekenkolom: `Geen herstart` |
| no undo | geen onged. | Bord-header: `Geen onged.` (Statistieken: `zonder ongedaan maken`) |
| win rate | Winst % | Statistiekenkolom |
| best time | Beste tijd | Statistiekenkolom |
| fewest moves | Min. zetten | Statistiekenkolom, verkort vanwege 100 kolommen breedte |
| unknown (solvable?) | onbekend | Oplosbaarheid niet gecontroleerd of onbeslisbaar: `Winbaar: onbekend`; Legenda `? onbekend` |
| not checked | ongecontroleerd | Oplosbaarheid niet gecontroleerd: `- ongecontroleerd` |
| Page Up / Page Down | PgUp/PgDn | Toetsen in voetteksten: `Omhoog/Omlaag/PgUp/PgDn: scrollen` |
| rejected move | Ongeldige zet: … | Prefix voor alle `board.error.*`; hele melding maximaal 40 tekens |
| hints and help | hints en hulp | Groep in instellingen |
| target marks | doelmarkeringen | Markeringen van geldige doelvakken |
| quick options | snelle opties | Optiepaneel tijdens het spel |
| face-up / face-down | open / dicht | Kaartstatus; dichte kaart |
| pick up / drop / put back | pakken / neerleggen / terugleggen | Kaartacties |
| undo / redo | ongedaan maken / opnieuw | Zetten terugdraaien of opnieuw uitvoeren |
| seed | seed | Willekeurige getalwaarde voor de verdeling |
| hint | hint | Zetaanbeveling |
| quick move | snelle zet | Direct naar beste doel verplaatsen |
| Spider | Spider | Ongewijzigd |
| Pyramid | Piramide | Vertaald met -e |
| Klondike | Klondike | Ongewijzigd |
| FreeCell | FreeCell | Ongewijzigd |
| Draw 1 / Draw 3 | 1 kaart / 3 kaarten | Trekmodus in Klondike |
| Relaxed / Classic | ontspannen / klassiek | Spelvarianten van Piramide |
| tab (UI) | tab | Tabblad in interface (Toets: Tab) |
| dock (help window) | vastzetten | Helpvenster zijwaarts vastzetten |
